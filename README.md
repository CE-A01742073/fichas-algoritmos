# Fichas de algoritmos

Sitio en Jekyll con las fichas técnicas del segundo periodo de Análisis y Diseño de Algoritmos Avanzados.

- Cada ficha está en `_fichas/<nombre>.md`. Para corregir texto, edita ese archivo.
- Los códigos completos también están en `codigo/`.
- Si el repositorio no se llama `<usuario>.github.io`, pon `baseurl: "/<nombre-del-repositorio>"` en `_config.yml`.
